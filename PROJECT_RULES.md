# Darkroom Timer — Regole permanenti del progetto

## Consolidamento della base sorgente

- Le modifiche minori possono essere applicate come patch incrementali.
- A ogni salto principale di versione, per esempio da `0.5.x` a `0.6.0`, creare una nuova base sorgente consolidata che incorpori tutte le patch precedenti.
- Consolidare anche prima del salto principale se le modifiche diventano strutturali/sostanziali o se si accumulano circa 8–10 patch.
- Dopo il consolidamento, la nuova base diventa il riferimento unico per le versioni successive e le patch precedenti possono essere archiviate.
- Prima di iniziare una nuova serie di modifiche, verificare questa regola e valutare se è il momento di consolidare.
