# Darkroom Assistant v0.2.1 — live index acceptance

The search brain must resolve names from live sources, not from a hardcoded product list.

Acceptance cases checked by CI against the live Massive Dev Chart index:
- `rod` → Rodinal
- `superg` → Rollei Supergrain
- `bell` → Bellini Hydrofen (and other Bellini developers)
- `fuji` → Fuji/Fujifilm films
- `agfa` → Agfa/AgfaPhoto entries
- Foma Universal, Ilford HP5+, Kodak Tri-X 400 remain discoverable

Any result from the Massive Dev Chart **Developers** index is classified as a film developer by provenance; page-text keywords may not turn it into fixer/stop.
